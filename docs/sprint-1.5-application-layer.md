# Sprint 1.5 — Application Layer

## Stack

- Backend: FastAPI (Python)
- Database: PostgreSQL 15+
- Frontend: React + Vite
- AI extraction: OpenAI Responses API with strict JSON Schema output

## Architecture rule

AI extracts business requirements and asks focused follow-up questions. AI does not decide product rankings and does not invent product facts. Product recommendations continue to come from `generate_consultation_recommendations` and the evidence-backed knowledge graph.

## Current browser flow

1. Visitor describes the business problem without creating an account.
2. Backend creates a hashed anonymous visitor session and consultation.
3. React opens the consultation chat.
4. User supplies company details, budget, integrations and constraints.
5. Backend sends the message and recent consultation context to the Responses API.
6. Structured extraction is stored in `ai_extraction_runs` as provisional data.
7. Follow-up questions are stored in `ai_follow_up_questions`.
8. The UI displays database readiness and missing critical fields.
9. Recommendation generation is blocked until `ready_for_matching=true`.
10. Once ready, the API invokes the deterministic v1 scoring engine and returns persisted ranked results.

## Important current limitation

AI-extracted values are intentionally not auto-promoted into canonical consultation tables. Sprint 1.4 defined model output as provisional until accepted. A follow-up change must add confirmation/mapping of extracted company, category, capability, integration, deployment, compliance, country, language and budget fields before a pure free-text consultation can reach matching readiness end-to-end.

This is deliberate: the first UI must not let uncertain model output silently change the authoritative requirement set.

## Local run

Apply all database migrations first, including `006_ai_consultation_contract.sql`.

Backend:

```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --reload --port 8000
```

Frontend:

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:5173`.

## Environment

`OPENAI_API_KEY` is optional for startup. Without it, the backend uses a safe fallback response and does not claim to have performed model extraction.

`OPENAI_MODEL` defaults to `gpt-5` and may be overridden in the environment.
