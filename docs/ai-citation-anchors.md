# AI citation anchors

TechSelectAI public pages should expose stable, human-visible fragment identifiers for important factual sections so search engines, AI retrieval systems, and human readers can link directly to the relevant evidence-backed content.

Required patterns:
- `#overview` for the page summary/hero
- `#capabilities` or `#capability-comparison` for capability facts
- `#product-support` for capability/integration support tables
- `#integration-comparison` for comparison integration tables
- `#deployment-comparison` for deployment comparison tables
- `#evidence` for source/evidence sections where present

Anchors are ordinary HTML identifiers shown to all visitors. They must not create crawler-only content or alter recommendation scoring.
