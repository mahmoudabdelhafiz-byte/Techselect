# AI-friendly factual summaries

Public TechSelectAI pages should summarize factual coverage in normal visible HTML, using the same data shown elsewhere on the page. Summary text must distinguish recorded facts from buyer-specific fit scoring and must preserve the rule that Unknown / Not Yet Verified is not the same as Unsupported.

These summaries are intended for both humans and retrieval systems. They must never be hidden from users or vary by crawler user agent.
